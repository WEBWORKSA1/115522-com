Three numbers from one name

Expression uses every letter and describes natural talents. Soul urge uses vowels (A, E, I, O, U) and describes inner motivation. Personality uses consonants and describes how others see you. The Chaldean total uses a different letter table based on sound and is the one most often used for name-spelling changes. Compare both in our numerology systems guide.
